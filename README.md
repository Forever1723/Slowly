# Slowly

> 慢慢来，比较快。

一个只属于你的每日记录小工具：写下今天想做的事，打勾，记下心情，然后看着日子一点点积累起来。

**不注册、不上传、不联网。** 数据存在你自己的设备上 —— 电脑上是 `%APPDATA%\Slowly\` 里的一个文件，手机上是浏览器自己的存储。

> 只想快点用起来？看 [快速开始.md](快速开始.md)。
> 想发布到网上给所有人用？看 [PUBLISH.md](PUBLISH.md)。

---

## 快速开始

双击 **`启动 Slowly.vbs`**

- 没有黑窗口，直接以一个独立应用窗口打开（没有地址栏，看起来就是一个软件）
- 想排错时改双击 **`启动 Slowly.cmd`**，这样能看到控制台输出
- 启动器找不到 Node.js 时会提示你去 https://nodejs.org 装 LTS 版本

首次启动会自动打开 <http://127.0.0.1:8787/>，并在 `%APPDATA%\Slowly\` 建好数据文件。

## 给所有人用（发布成网站）

`docs/` 目录就是可以直接发布的网站：每个人打开网址就是一个属于自己的 Slowly，各自的数据存在各自设备上，**不需要服务器、不需要账号、不花钱**。

```
把 Slowly 文件夹 push 到 GitHub
→ 仓库 Settings → Pages → 分支 main、目录 /docs → Save
→ https://你的用户名.github.io/仓库名/
```

详细步骤（含 Vercel / Netlify / 自有服务器）见 [PUBLISH.md](PUBLISH.md)。

改了代码后重新生成：

```
node tools\build-offline.mjs     # 同时更新 docs/、单文件版、安卓工程内嵌页面
```

## 手机上也能用（同一个 Slowly）

手机端有三种用法，从轻到重：

### ① 直接连电脑（最省事，数据只有一份）

1. **让手机和电脑连同一个 WiFi**
2. 在 Slowly 里点底部 **「🔗 连接」**，会看到一个二维码和一行地址
3. 手机扫码即可；扫不出来就把那行地址手动输进手机浏览器
   - 形如 `http://192.168.x.x:8787/`
4. 在手机浏览器里选「添加到主屏幕」，它就会像 App 一样有个图标，点开没有地址栏

这种用法下手机不存数据，界面和手机每次都从电脑取 —— 电脑关机就打不开了。

### ② 手机独立版（推荐，电脑关机也能记）

在电脑端「🔗 连接」页往下看，有一张 **「手机独立版」** 卡片，用手机扫那个二维码（或直接在手机浏览器打开 `http://<电脑IP>:8787/api/offline`），
浏览器会把一份 **90 KB 的单文件 Slowly** 存到手机上。

- 它是完整的 Slowly：目标、心情、随笔、统计，一样不少
- **数据存在手机自己身上**，电脑关机、不在同一 WiFi、断网都能照常记录
- 回到同一 WiFi 后，在「🔗 连接」页点一次 **立即同步**，手机与电脑的数据就会合并
  - 合并规则：按条目的时间取新的那一份，两边的新记录都不会丢
  - 手机上删掉的东西会留下"墓碑"，同步后电脑上也会删掉，不会被复活
- 也可以把下载到的 `Slowly-offline.html` 用数据线/微信传过去，用浏览器打开

### ③ 编译成真正的安卓 APK（有独立图标和外壳）

`android/` 目录里是一份**完整的安卓工程**（WebView 外壳 + 已经打包好的离线界面 + 图标），
编译出来就是一个可以安装、可以分享的 APK。

这台电脑上没有 Java / Android SDK 也没网络，所以编不了；换一台有 Android Studio 的电脑，
或者用 GitHub Actions 云端编译（免费，3~5 分钟）：

**详细步骤见 [`android/BUILD.md`](android/BUILD.md)。**

## 手机连不上时（九成是防火墙）

- 右键 **`让手机能连上（管理员运行）.cmd`** →「以管理员身份运行」，跑一次就行
- 或者手动放行：Windows 安全中心 → 防火墙和网络保护 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 8787 → 允许
- 还不行就确认：电脑和手机是同一个 WiFi？路由器有没有开「AP 隔离」？地址里的 IP 是不是电脑当前的 IP？

---

## 两端是怎么同步的

- 电脑上的 Slowly 服务器是**唯一的真实数据源**，数据写在 `%APPDATA%\Slowly\slowly-data.json`
- 任何一端的改动都会立刻发给服务器，服务器落盘后再广播给另一端 —— 手机上打个勾，电脑上马上就能看到，还会标出「这是手机做的」
- 连接状态在右上角：绿点＝已同步，橙点＝已断开（改动会失败并提示）
- 每天第一次写入时自动在 `%APPDATA%\Slowly\backups\` 留一份备份，最多保留 14 天
- 数据文件是**原子写入**的（先写临时文件再改名），断电也不会留下半个文件

## 数据在哪、怎么带走

| 项目 | 位置 |
|---|---|
| 数据文件 | `%APPDATA%\Slowly\slowly-data.json` |
| 每日备份 | `%APPDATA%\Slowly\backups\slowly-YYYY-MM-DD.json` |
| 应用窗口的浏览器配置 | `%APPDATA%\Slowly\window-profile\`（可随时删） |

换电脑时：把 `slowly-data.json` 拷到新电脑的同一个位置，或在应用里用「导入备份」。

建议偶尔点一次 **「导出备份」**，得到一份 JSON 存到网盘或 U 盘。

## 命令行的用法

```bash
node server.mjs                  # 启动并打开浏览器
node server.mjs --app            # 以独立应用窗口启动（默认由启动器使用）
node server.mjs --no-open        # 只启动服务器，不打开窗口
node server.mjs --port 8899      # 换端口
node server.mjs --quiet          # 不打印启动信息
node server.mjs --data D:\x.json # 指定数据文件位置
```

端口被占用时它会提示，并建议换端口。

## 自己跑一遍测试

```
node test\qr.test.js          # 二维码编码器：54 项
node test\server.test.mjs     # 服务端接口与持久化：41 项
node test\ui.test.mjs         # 前端界面逻辑（连真实服务器）：61 项
node test\offline.test.mjs    # 手机离线版 + 与电脑合并：31 项
node test\site.test.mjs       # 发布站点（模拟 GitHub Pages 子目录）：21 项
node test\static.test.mjs     # 接线检查 + 离线包 + 安卓工程：72 项
node test\shortcut.test.mjs   # 快捷方式与图标：23 项
```

这些测试不是走个过场：

- **二维码**：把编码结果用一套独立的解码流程解回来逐字节比对，并校验里德-所罗门校验位、格式信息的汉明距离、遍历顺序一致性 —— 也就是说"手机扫得出来"这件事是被证明过的，不是猜的
- **服务端**：真的起一个服务器进程，测并发写入（12 个请求同时打）后磁盘与内存是否一致、原子写入有没有留临时文件、重启后数据还在不在
- **前端**：把页面脚本放进浏览器式沙箱里跑，用真实的 `fetch` 连真实服务器，验证每一次点击都产生了正确的接口调用和界面变化，包括"手机改动实时到达电脑"这条链路
- **离线版**：把打包出来的 `offline.html` 当成 App 跑一遍 —— 断网（让所有 `/api/` 请求直接失败）也能记录、数据落到本机；接上真实服务器后验证两边合并、冲突取舍、离线删除的墓碑是否生效；并校验客户端与服务器的合并规则给出**完全相同**的结果
- **发布站点**：真的起一个静态服务器、挂在子目录下（模拟 `用户名.github.io/仓库名/`），确认页面、manifest、Service Worker、图标都能取到；确认访问者在**启动与记录全程零网络请求**（也就是隐私承诺是真的）；确认刷新后数据还在

## 重新打包

改了 `public/` 下的前端代码后：

```
node tools\build-offline.mjs
```

它会重新生成 `public/offline.html`，并同步到 `android/app/src/main/assets/index.html`，最后自检两者是否一致。

## 目录结构

```
Slowly/
├── 启动 Slowly.vbs            静默启动（推荐双击这个）
├── 启动 Slowly.cmd            带控制台的启动（排错用）
├── 让手机能连上（管理员运行）.cmd
├── server.mjs                 本地服务器：静态文件 + REST + SSE + 原子写入
├── lib/qr.js                  自己实现的二维码编码器（零依赖）
├── public/                   前端
│   ├── index.html
│   ├── app.js
│   ├── manifest.webmanifest   加到手机主屏幕用
│   └── sw.js                  离线外壳
├── assets/                    图标（SVG / PNG / ICO）
├── tools/
│   ├── make-icon.mjs          生成图标（手写 PNG 编码，零依赖）
│   └── make-shortcut.mjs      生成 Windows 快捷方式（手写 .lnk，零依赖）
└── test/                      测试
```

整个项目**没有任何第三方依赖**，不需要 `npm install`。
